## How to run a project

1. Clone the repository:

   ```bash
   git clone https://github.com/YasirRasheed4/arch-technologies-android-app-internship.git
   ```

2. Open a single project folder in **Android Studio**.
3. Wait for Gradle to finish syncing.
4. Run the app on an emulator or a physical Android device.

> Open each project on its own, not the repository root, since every app is a separate Android Studio project.
